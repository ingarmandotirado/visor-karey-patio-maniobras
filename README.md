# Karey Alimentos · Patio de maniobras y autobaño

Visor 3D (three.js) del anteproyecto: patio de maniobras de 25 × 276.60 m, techumbre de resguardo (4.50 m libres),
área de lavado, caseta de vigilancia, cisterna, transformador y barda escalonada en 6 tramos (NPT ±0.00 → +1.50).
Incluye el timelapse del proceso constructivo (botón "Proceso constructivo"), vistas rápidas, sol real y modo nocturno.

## Versiones
- [v3](v3/) — 24-10-2026 · compatibilidad con iPhone: calidad ligera automática en celulares, menos memoria gráfica, polyfill de import maps para iOS anterior a 16.4 y mensaje en pantalla si el 3D no puede cargar.
- [v2](v2/) — 24-10-2026 · camiones que entran y salen con el portón animado, autobaño equipado (arcos de lavado con rocío, señalética, cortina de PVC, tanque, lavadores) y alumbrado nocturno más suave.
- [v1](v1/) — 24-10-2026 · primera versión desde el DXF planchado (techumbre a 4.50 m libres).
