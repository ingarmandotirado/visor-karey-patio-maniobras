# Karey Alimentos · Patio de maniobras y autobaño

Visor 3D (three.js) del anteproyecto: patio de maniobras de 25 × 276.60 m, techumbre de resguardo (4.50 m libres),
área de lavado, caseta de vigilancia, cisterna, transformador y barda escalonada en 6 tramos (NPT ±0.00 → +1.50).
Incluye el timelapse del proceso constructivo (botón "Proceso constructivo"), vistas rápidas, sol real y modo nocturno.
